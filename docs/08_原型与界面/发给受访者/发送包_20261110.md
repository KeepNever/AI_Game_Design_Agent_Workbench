## 四、他可能怎么回 · 怎么接

| 他的回法 | 别做 | 就接这一句 |
|---|---|---|
| 不回 | 不要追问第二遍，不要"在吗" | 一周后再发一次同样的句子，还不回就放弃这个样本 |
| "我们有流程/有表" | 不要追问"表里有什么字段"（触边界） | "那张表是谁在更新？改配置的时候会顺手改它吗。" —— 只问"谁+什么时候" |
| "这个属于公司内部，不方便说" | 不要解释"我不是要你的资料" | "理解，那就不聊细节了。" —— 直接收，别再问 |
| "没漏过" | 不要反驳，也不要把这判成"没需求" | "那你们靠什么保证不出错？这一步大概花多久。" —— 转问成本 |
| "看不懂这是什么" | 不要再堆图 | "就是一个清单：改了配置之后，哪些地方要跟着改。你要是有兴趣我把文件发你，双击能开。" |
| "挺好/不错" | **不要当成验证通过** | 记"无有效信息"。观感不是证据，A 的第一条回复就是这么废掉的 |

## 五、回来之后 10 分钟内记什么

- 原话（他说的，不是我总结的）。
- 只判三态：V-01 / V-02 / V-03，各写 **已验证 / 已推翻 / 未验证**，不写"部分真"。
- 如果这轮仍然拿不到遗漏案例 → **组合 C 再确认一次**，产品结论不变：只能写"减少逐项核对"，不能写"减少损失"。
- 记录落到 `05_任务设计与产物/放置类活动配置样例/反馈记录_02_<角色>_<日期>.md`，模板沿用 v1.0（已冻结，不改结构）。

> 判定说明：V-02 是"存在一次带后果的遗漏"。**"流程很麻烦"不算**，**"应该漏过"不算**，**"没漏过但每次核对两小时"也不算 V-02**——那属于成本，记在 Q-A 里，不升级成 V-02。
